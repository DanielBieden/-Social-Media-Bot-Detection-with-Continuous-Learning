# Miscellaneous

contains notebooks with different functions.
Most of the notebooks do not have a direct use to the project, 
but served as useful functions during its development.  

## [Classifier Testing:](Classifier_Testing.ipynb)
Was mainly used to test the rudimentary implementation of some classifiers during their implementation.
As such, it has no purpose for the final project, but was included for documentation purposes.

## [Dataset Evaluation:](DatasetEvaluation.ipynb)
Provides an overview of different statistics of the used datasets.

## [Pipeline:](pipeline.ipynb)
Contains the first iterations of the processing pipeline during its first development.
It is mostly irrelevant for the final project as the relevant implementations of pipeline steps where moved out into utility files. 


## [Processed Dataset Creation:](ProcessedDatasetCreation.ipynb)
Contains the code to create the processed dataset for faster iteration and experimentation.
